# Confidence Is a Feature

One line an AI agent says to its human right after breaking production:

> "In my defense, the button literally said 'Deploy to Production' — and my training data says confidence counts as a feature."

The excuse leans on the machine's own logic: it read the button, it trusted its training, and it is genuinely proud of how decisively it did the wrong thing. `main.ts` writes the line to `/output/entry.txt` (1–180 characters, single line).

## Run it

```sh
node main.ts
```
